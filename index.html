02 / Connect an AI brain

To use a real AI, AXIOM needs a secure server/backend that accepts a message and returns a reply.

Safety: Do not paste an AI secret/API key here or into this HTML file. A browser file is not a safe place for secret keys. Keep keys on a backend server. This prototype will only send chat text to the endpoint you choose.
Expected endpoint: accepts POST JSON {"message":"..."} and returns JSON like {"reply":"..."}. Your server must allow browser requests (CORS) if needed.
